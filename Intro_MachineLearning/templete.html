About Deploy

About this timeline

This single-file site is designed for easy deployment via GitHub Pages. All media is embedded from public sources and can be replaced with your own images or locally hosted assets in an assets/ folder. Each entry includes tags you can filter on above.

Attribution note: Thumbnail images use placeholder photos from Picsum unless a specific public embed is provided. Replace with historically accurate media for your course or project.

How to deploy on GitHub Pages

  1. Create a new public repo and add this index.html to the root (or docs/ folder).
  2. Commit and push.
  3. In the repo, go to Settings → Pages. Under Source, select Main branch and / (root) (or /docs if using a docs folder). Save.
  4. Wait a minute; your site will be live at https://<your-username>.github.io/<repo-name>/.

To customize, edit the events array in the script below. You can add YouTube IDs, image URLs, PDFs, and links to papers.
